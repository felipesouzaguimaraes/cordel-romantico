Este projeto consiste em uma página web poética e interativa baseada na obra da cordelista **Fátima**. O grande diferencial deste repositório é que ele foi desenvolvido como uma **dedicatória exclusiva à minha esposa, Geovana**.

> 📜 *"Botei a rima no código, O sentimento no papel, Pra dizer que o nosso amor, É mais doce que o mel."*

Tecnicamente, o site utiliza os mesmos conceitos avançados do Módulo 3 do curso do Curso em Vídeo (Prof. Gustavo Guanabara), aplicando imagens de fundo fixas com rolagem dinâmica para dar vida e sensibilidade aos versos.

## 🎨 Características do Projeto e Conceitos Aplicados

O design e a estrutura foram adaptados para transmitir romantismo e leveza por meio do código:

| Elemento Técnico | Aplicação Prática |
| :--- | :--- |
| **Efeito Parallax** | Configuração de propriedades como `background-attachment: fixed` para fazer os blocos de poemas deslizarem suavemente por cima das imagens de fundo. |
| **Semântica Emocional** | Organização rigorosa de tags HTML5 para estruturar estrofes, versos e a mensagem especial de carinho no rodapé da página. |
| **Harmonização Visual** | Seleção de tipografia artística e cores que contrastam de maneira sutil e elegante, otimizando a legibilidade e a imersão na leitura. |

## 📂 Estrutura de Arquivos do Repositório

* `index.html` — Estrutura e marcação com as estrofes poéticas e a dedicatória.
* `estilos/` (ou pasta de CSS correspondente)
  * `style.css` — Estilização, centralização dos versos e lógica visual do efeito Parallax.
* `imagens/` — Imagens selecionadas para ilustrar o fundo das transições textuais.

---

## 🚀 Como Executar Localmente

Como é um projeto puramente estático de Front-End, basta:

1. Clonar ou baixar esta pasta.
2. Abrir o arquivo `index.html` em seu navegador.
3. Rolar a página para apreciar o efeito visual combinado com as rimas da poesia.
